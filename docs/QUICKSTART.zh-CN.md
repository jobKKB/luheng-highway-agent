# 路衡 0.3 体验指南

这份指南适用于本机已启动的中文客户端。0.3 是供测试的开发原型；Windows 安装包尚未生成和验收：已尝试云Linux交叉构建，Windows Electron下载并校验成功，但Windows Chromium官方下载返回不可用页面。开发侧仍负责打包，用户只需在收到安装包后进行Windows运行测试。源码 ZIP 的构建方式在 `DESKTOP.md`，不能直接当安装器使用。

## 不填任何账号，先体验四件事

1. 点击首页“养护周报”，提交任务。进入任务中心查看步骤、引用来源和完成结果，再下载文本文件，也可导出Word报告（DOCX）和Excel执行台账（XLSX）。这些是实际文件，台账列出本任务执行步骤与状态，不会凭空补造业务数据。样例资料是虚构数据。
2. 点击“OA 事务办理”。任务会先停在审批处；可以拒绝，也可以人工接管。确认内容后批准，内置模拟页面会真实增加一条测试记录。
3. 打开“智能体团队”，编辑名称、职责和性格；按需要启用权限。角色缺少所需权限时任务会停止，不会绕过设置。
4. 创建一个几分钟后的提醒。保持应用打开，到期后查看右上角通知。默认关窗口后不再检查；下次启动会把关机期间到期的提醒补记一次。托盘可用且明确开启后台运行后，关窗口仍会运行。

首页“任务演示模式”表示模型任务使用固定演示逻辑，不代表智能体已经理解并能完成任意指令，也不代表独立邮件工作台只能演示。

## 接入自己的模型服务

在“设置”里切换到 API 模式，填写服务商提供的基础地址、模型名称和 API Key。基础地址通常以 `/v1` 结尾；程序会自行添加 `/chat/completions`，不要重复填写这一段。

- 当前仅支持公网 HTTPS、443 端口和 OpenAI 兼容 Chat Completions 工具调用协议
- 每个角色也可在团队编辑页使用不同模型和 Key，或继承全局配置
- 默认密钥仅在本次运行内存中使用。桌面设置里可勾选明确同意后保存当前模型与邮箱凭据的系统加密快照；修改后需再次点保存，不会自动更新
- 安全密钥库不可用时按钮禁用，不会用明文凑合保存。忘记快照后下次启动不再恢复，本次运行内存凭据仍可用
- 任务及执行所需资料会发给所选模型服务商；只输入符合单位外发要求的资料
- 任务操作次数预算不是费用封顶，服务商仍可能计费
- 本次交付未接真实商用模型，连接与结果质量需使用自己的服务另行验证

## 知识与角色

“知识与记忆”可保存实际文本和来源，选择共享或某个角色私有。当前是本机单用户管理，所有条目对应用使用者可见；私有范围限制的是智能体模型的上下文读取与委派。

角色读取私有资料、邮件或受控网页后，整个任务不会再委派给其他角色。需要跨角色处理时，另起任务并明确提供可共享的材料。当前没有企业级多人权限系统。

## 邮件工作台

需要自己的 IMAP/SMTP 地址、账号和本次运行密码；支持 TLS 或强制 STARTTLS。先读取收件箱，再起草、编辑邮件。发送前的弹窗会展示服务商、发件人、全部收件人、主题和完整正文。

批准后会尝试真正发信。若提示“投递结果未知”，邮件可能已经交给服务器，不能直接再次发送；先在实际邮箱核实。SMTP 确认接收也不等于收件人已读或最终入箱。本版不支持附件、OAuth 或 HTML 邮件。

本次邮件验证使用本地虚构邮箱服务器，没有使用真实外部账号，也没有向外部收件人发信。

## 受控浏览器

先保存明确授权的目标，再打开独立浏览器会话。观察文字、截图与控件列表后，提出具体填入/点击动作，核对完整动作审批。批准前不会输入。

人工接管时智能体暂停；归还后重新观察，旧审批作废。输入已执行不等于业务保存成功，应核对页面显示结果。结果未知时先人工核实，不要盲目重做。

本版仅开放公网 HTTPS 443 目标；尚不支持单位内网、已有浏览器登录态、密码/验证码输入、复杂 SSO、上传下载和任意脚本。两套本地虚构网页已通过功能测试，真实单位网页与独立安全审查仍待完成。

## 周期任务与时区

在“周期任务”中创建任务，可选择每隔若干分钟、每天固定时刻或每周指定星期。填写明确的IANA时区，例如 Asia/Shanghai，下一次执行时间会显示时区与UTC。保存前核对任务内容和预算；API模式下每次触发都可能产生模型费用。

- 可编辑、暂停、恢复或取消；取消后不能恢复，可另建新计划
- 程序必须运行，电脑休眠或关闭时不执行。恢复后合并错过周期为最近一次，不逐个补跑
- 夏令时跳过不存在的当地时刻，重叠时刻只选择第一次；间隔任务按真实经过分钟计算
- 主动检查关闭时不会触发；恢复主动检查时继续按合并规则处理
- 计划不会批准网页输入或邮件发送；这些仍停在正常人工确认流程
- 计划取消只阻止以后触发，已生成任务需单独停止

## 桌面托盘

设置中的“关闭窗口后继续运行”默认关闭，仅托盘可用时能开启。开启后点击窗口关闭会隐藏到托盘，可由托盘恢复；托盘菜单“退出路衡”才停止后端。此选择不设置操作系统开机自启。重启电脑后仍需自己打开程序。

## 数据、退出与停止

- 任务、知识、审批、提醒和产出保存在本机；没有跨设备同步
- 随时可在任务中点击停止。已经交给外部系统的操作不一定能撤回，界面会保留相应结果
- 默认关闭窗口停止执行；明确开启托盘运行后须从托盘退出。没有开机启动或云端全天执行
- 本地资料未做静态加密，应按单位要求保管电脑与备份
- 首次真实业务试用，应使用脱敏资料和可撤回的小范围测试
