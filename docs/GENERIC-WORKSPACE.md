# 通用工作空间开发候选

此候选基于0.5.2稳定DOM源代码，不是已经发布或验收的Windows安装包。

## 对话入口

白色连续消息区、独立下载卡片、固定底部宽圆角输入框。消息保留用户/助手身份，执行记录默认折叠；仅显示执行步骤与工具结果，不显示模型隐秘推理。空输入、模型未配置或当前轮仍运行时，发送按钮不可用。Ctrl/⌘ Enter发送，Ctrl/⌘ K新建对话；中文输入法组合期间快捷发送不生效。

跟进请求传递真实previousTaskId，只能继续同角色已完成且正文仍可用的任务。最多传递前三轮公开用户消息与最终答复，合计16K字符，不传递模型思考或工具上下文。换角色、待人工核实或重启后已清除的正文需新建对话，未知副作用不能重放。新对话不自动启用Skills。

## 配置与工具

新安装默认API模式，知识库与旧演示收件箱为空。未配置模型不会生成养护、邮件或OA假结果。原始养护确定性模板、草稿流程和模拟网页入口已经从运行路径中移除；真实邮件、受控浏览器、本机权限与预算边界保留。

输入框工具按钮与顶部“工具与能力”始终可见，读取服务提供的能力清单。可用、未配置、权限受限、未实现分别展示；配置就绪不代表网络已探测。页面说明最后一次网络观察，包括限流/服务不可用；云端观察不能保证中国境内网络可达。任意附件解析尚未实现，入口诚实说明当前支持Skills文本包和知识文本。

## 完成核验与上下文边界

用户明确要求保存文件、提供下载链接、发送邮件等动作时，结束核验会检查相应真实工具回执。模型自报stable或“已保存”不能代替文件与回执；不同动作的回执不能互相代替。仅写作、说明操作方法、普通与历史知识问答可直接在对话中回答，不强制创建文件。未核验答复会先显示未完成原因，再标明模型答复尚未核验。

当前事实来源必须包含实质正文和近期内容日期。retrievedAt只证明取回时间，不能把2020旧页面或只有URL/标题的检索条目当作当前事实。正文与日期无法确认时返回needs_attention；这是一组保守的完成校验，不能保证任意自然语言结论都已被来源语义证明。

只读委派读取共享工作区资料也会在子模型接收资料前设置并保存非公开上下文标志，后续自动公网检索不可用。没有工作区资料的只读委派仍可使用公开检索。公网每次MCP子请求、DNS返回与跳转连接前重新检查当前角色、任务和上下文权限；撤权不能被早先的schema快照覆盖。HTTP200不等于MCP工具成功，限流/无效结果分别记录服务不可用观察。

## 用户Skills

由用户选择SKILL.md文件或包含根SKILL.md的目录文本包；不读取任意服务器路径、不加载脚本、不运行Shell、不安装依赖、不扩大角色/全局权限。单个文件64KB、整包256KB、最多24个文本文件（md/txt/json/yaml/csv）；根SKILL.md包含单行name/description头部。服务将包保存到固定私有目录的内容哈希位置，校验路径、格式、大小、重复项、篡改与符号链接。最多同时选4个Skills、正文合计64KB；导入不会自动启用，选择后下一次发送会把正文提供给模型。任务创建时冻结正文，后续修改不改变正在执行的任务。

此最小实现不支持脚本资源执行、依赖管理或Skill市场。资源仅供只读查看；这是明确边界，不是假装已经实现完整Hermes插件系统。实现未复制Hermes源码。

## 旧资料迁移与恢复

幂等迁移仅按固定原始ID、标题、内容、来源、版本和未新增编辑字段完全匹配的旧seed样例归档。用户修改、自建资料及已有角色权限保持原样；没有给旧角色自动加web.read。新安装默认角色拥有所需的新权限，旧角色由用户自行授予。

归档完整原记录保存在同一私有数据库，设置页可按条查看/恢复；恢复不会启用旧演示，也不能覆盖现有资料。任务记录和用户交付文件不因去演示而删除。

## 验证

运行：node --test tests/generic-skills.test.mjs tests/public-web.test.mjs tests/public-web-engine.test.mjs tests/model-transport.test.mjs tests/stable-dom-flicker.test.mjs tests/stable-dom-selection.test.mjs tests/new-task-focus-independent.test.mjs

浏览器验收脚本：node tests/generic-chat-ui.mjs。只使用合成数据、临时SQLite、临时Chromium profile与模型completion夹具，不使用真实Key、邮箱、OA或客户实例。涵盖桌面/360px、Markdown与链接安全、真实文件下载、会话历史、工具/Skills、DOM身份、输入法、文本选择、手动滚动与实际60秒idle轮询。

当前云执行环境中Chromium在Unix socket建立时返回EPERM，默认与获准的独立测试执行均失败；云浏览器拒绝loopback导航。因此真实浏览器脚本尚未运行至页面，未生成本次UI截图，Windows/实际手机也未验收。此限制不能用合成DOM测试替代。后端旧demo预期已迁移为明确合成API工具夹具、空白安装、归档恢复及旧入口fail-closed合同。原浏览器UI脚本保留历史，由新的自动push/PR Windows门禁替代；环境阻断下仍不能把Node/合成DOM通过称为完整UI通过。

原生安装器门禁在此独立候选已精确调整至0.6.0-candidate.2，并验证包内真实Chromium的sandbox参数与合成HTML。实际Windows执行、截图、安装和升级仍待对精确commit验收；旧升级锁/driver保持原样。
