# 本机访问权限候选：文件与命令

## 使用流程

安装并首次打开应用后，在聊天页出现权限引导。默认不连接本机文件与命令；取消或稍后设置不会授予权限。授权前选择允许访问的文件夹，桌面版使用系统原生文件夹选择器；源码浏览器版可填写本机绝对路径。文件夹选择本身不会授予权限。

聊天输入框旁的权限按钮始终显示当前模式，点击即可调整、修改文件夹或撤销：

- 未连接：本机工具不能执行，已有演示工作区、邮件与受控浏览器继续沿各自权限流程运行
- 只读：可列举授权文件夹、读取普通纯文本文件；不能写文件或运行命令
- 操作前确认：可读授权文件夹；每次文件写入与每条本机命令必须在对话中确认完整快照
- 完全访问：修改文件与运行命令不逐项询问；必须通过绑定所选范围的二次风险确认。文件工具默认仍限所选文件夹；另有明确的“全部文件”选项，不能从普通模式直接开放整盘

完全访问只适用于当前运行，程序重启后降为操作前确认，并关闭“全部文件”。旧的待审批或执行中操作在重启后失效，不重放。

操作审批绑定操作ID、内容摘要、程序与参数、工作目录、超时、任务身份和当前权限版本。一次批准只执行一次；改动模式/范围、拒绝、撤销、任务取消、超时或重启都会使原审批失效。通过模型工具传入 approval=true、mode 或其他未开放字段不能跳过后端校验。

## 已连接的实际工具

1. local_list_files：读取授权文件夹最多200条目录项
2. local_read_file：读取不超过256KiB的普通UTF-8纯文本
3. local_write_file：写入或覆盖普通纯文本文件，内容最多256KiB；确认模式展示完整目标与内容，批准后真实执行
4. local_run_command：直接启动用户明确批准的绝对路径可执行程序、参数数组和工作目录。默认15秒，允许100毫秒至60秒；stdout与stderr总计最多64KiB，并发最多2个。不隐式经过Shell、不支持交互stdin；Windows脚本须明确指定powershell.exe或cmd.exe和精确参数

智能体调用同时受到角色 files.read / files.write / commands.run 权限与全局本机授权约束。只有未修改的内置角色才会迁移必要默认权限，既有自定义或已修改角色不会被自动扩大权限。子角色委派仍保持原只读研究边界。

## 重要安全边界

这些是应用层授权与文件工具约束，不是Codex级操作系统沙箱。

- 文件工具校验绝对路径、规范化范围、文件类型，并拒绝路径内符号链接、Windows目录联接、普通文件硬链接、设备/进程接口、已知凭据目录及应用内部文件/数据库。Windows还拒绝UNC/设备路径、备用数据流及不规范保留名称
- 文件操作对打开的文件描述符及路径身份再次校验；但可移植Node API不能替代OS对抗恶意本机进程的完整隔离。另一个同权限进程恶意竞态、被用户批准的命令或用户直接改动数据库，均不属于可靠隔离保证
- 真实命令以当前用户已有权限运行。所选文件夹限制文件工具和命令工作目录，不限制命令读取其他文件、联网、启动程序或产生其他副作用。批准任意解释器/脚本等于批准其实际执行能力，不能视为已获得文件夹沙箱
- 完全访问不能自动取得Windows管理员权限，不能自动授予macOS完全磁盘访问、辅助功能或屏幕录制权限，也不会绕过系统安全弹窗
- 本候选连接的是文件和命令。没有承诺已集成通用截图、鼠标/键盘控制、所有系统应用自动化、PTY终端或系统级隔离
- 撤销立即阻止新动作、使旧审批失效，并请求终止受管理进程树；已写入的文件、已经发送的网络请求等不能自动撤回。刻意逃逸到新会话的子进程不保证可终止
- 子进程只继承最小环境变量，不继承模型/邮件Key、NODE_OPTIONS等。已知内存凭据不能作为命令/写入参数；输出进行已知凭据及常见密钥模式脱敏。这不是对任意未知敏感内容的完美识别
- API模式下，读取的文件内容与命令输出会进入配置的模型服务上下文。应遵守单位资料保密规定，不授权含秘密的文件夹，也不要批准读取凭据的命令

## 记录与恢复

权限策略和不含文件内容、命令参数或输出的操作元数据保存在本机SQLite。具体待审批快照、工具结果与本机任务的模型上下文只在当前运行内存保留；关闭程序后需重新发起，不恢复秘密上下文。运行中用户能在对话查看真实结果与审批；历史保留状态和动作种类，不能当作完整内容审计或企业防篡改日志。用户明确生成的工作区文稿、Office导出或邮件草稿仍会按各自工具语义保存到其指定目标，这不属于内部任务日志的自动内容留存。

## 验证范围

使用隔离临时目录、虚构文件、无害Node命令和无Key实例进行Linux单元、集成、安全回归与DOM/状态机测试。当前云环境的Chromium启动被Unix socket权限限制，真实浏览器交互与像素验收尚未通过；独立浏览器UI套件已列入Windows CI，须以该候选实际运行结果为准。测试不开放宿主整盘，不读取真实凭据，也不修改系统安全设置。Windows优先设计已实现路径算法与exe启动/进程树终止分支；新增功能的原生Windows安装后交互、macOS系统授权及真实用户模型仍需单独验收，不能由Linux测试或旧Windows构建成功替代。

## 集成后的本地上下文可见性

配置模型模式且执行角色具有任一本机工具权限的任务，从创建前即以本地上下文处理（即使全局访问当前关闭，以防运行中授权改变）。用户任务正文、工具参数、读取内容、命令输出、完成摘要及详细错误只存本次运行内存；数据库及 WAL 从首次保存就只接收显式白名单元数据。重启后显示安全占位，未完成任务停止待人工核实，旧待批操作不能恢复或重放。

聚合 `/api/state` 不返回这些内容或本机待批参数；已认证的按任务详情与本机审批详情在当前会话按需可见但不持久保存。界面仅为当前选中的任务读取详情，切换任务、导航或取消后的迟到响应不会替换新选中的内容。明确导出已完成任务仍使用内存中真实结果；生成文件是用户显式请求保存的交付物，下载须具备会话认证、任务注册和所属角色文件权限。

本地任务重启后可以继续下载或复用已经生成的交付文件，保留文件大小与SHA256元数据；尚未生成的导出格式会拒绝创建，避免把安全占位文字伪装成原始任务结果。

## 审批摘要与中断结果

本机操作内容及工具参数使用每次运行随机密钥的 HMAC 绑定，密钥只保留内存，不写入数据库；本机任务的提交内容指纹也只保留内存。当前运行中相同提交标识可安全重试，内容不同会拒绝。重启后无法核对原始本机任务内容，因此旧提交标识明确拒绝，须先核实已有操作再以新标识发起；没有本机上下文的任务仍保留原有跨重启幂等行为。用户明确持久保存的交付文件继续保留 SHA256 供文件完整性核对。

本机上下文任务中断时，会核对实际邮件发件箱与网页审批记录，并保守保留可信的既有结果标记。SMTP 已接受或投递结果未知、网页输入已执行或结果未知，都保留固定的安全结果代码与“不可重复发送/执行”提示，状态为待人工核实；未知结果不能被改称尚未执行或普通失效。记录不包含原始正文。命令只有退出码严格为0才标为完成，非零退出及信号终止均为失败证据。
