# v0.4 界面与桌面体验更新

## 设计

- 冰蓝白底、深海蓝文字、海蓝主操作。所有界面使用同一套间距、圆角、图标、输入与状态样式
- 首页以输入框为中心。工作工具、概览、最近任务、模型/角色选择默认折叠，需要时展开
- 桥梁与海岛使用原创本地 SVG，不包含参考截图、远程字体、CDN 或付费素材
- 任务在聊天主区显示需求、执行过程、结果与审批；执行过程可折叠，输入区域与消息滚动区分开
- 已完成的每条任务仍保存在任务记录中；输入下一项工作会创建独立任务，当前版本不冒充自动承接所有前文的多轮聊天
- 提升正文与说明字号、对比度、键盘焦点、空状态和失败提示。兼容窄屏、手机宽度与减少动态效果偏好

## 交互与桌面

- 修正输入框获得焦点时快捷键导航不切页、浏览器返回空锚点不回首页、轮询更新被输入焦点阻塞后不补渲染的问题
- 保留未发送草稿；过时的提交响应不清空新草稿，也不覆盖更新的导航意图
- 关闭弹窗后恢复触发控件焦点；危险操作按钮使用资源级并发防护
- 原生窗口可拖拽缩放、最小化与最大化。一般最小尺寸为900×620 DIP，较小工作区会适当降低
- 保存正常窗口位置、尺寸和最大化状态，显示器移除或工作区变化后把窗口移回可见区域
- 默认关窗即退出；只有用户明确开启并有可用托盘时，关窗才保留后台。托盘退出停止任务

## 模型连接改进

- 使用部署环境已有的 HTTPS 代理和已有受信 CA 配置；不会创建代理、改系统网络或关闭证书验证
- 代理选择遵循原目标域名的 NO_PROXY。实际直连与 CONNECT 连接均使用已校验的公网 IP，保留原域名 Host/SNI 与 TLS 校验
- 区分 DNS、TLS、连接拒绝、网络不可达、超时和代理错误，提供不含密钥/端点/请求正文的诊断编号复制
- 不重试可能计费的模型调用，不把缺少凭据时的HTTP401当成模型测试成功
- 需要 Node.js 24.5+；打包 Electron 内置运行时已满足要求

## Windows 构建修复候选

- 合并 Windows Office 导出权限修复：使用系统自带 PowerShell 设置并回读原生 DACL，不能用 POSIX 的0600断言代替Windows权限
- 保留独占创建和链接拒绝；修正桌面凭据测试错误固定为Linux平台的问题
- 本次仅完成 Linux 合并回归。原生Windows ACL、安装器构建与安装卸载尚未验证，见 `docs/WINDOWS-PERMISSIONS.md`
