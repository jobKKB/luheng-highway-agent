# 0.3 实现范围与剩余工作

## 本版新增

- 持久周期任务：IANA时区、间隔/日/周、错过合并、编辑/暂停/恢复/取消与唯一任务实例
- 可选桌面托盘关闭后运行，默认关闭退出，不启用操作系统自启
- 可选系统加密凭据快照与配置绑定恢复，不可用时拒绝保存，默认仅内存
- 已完成任务导出真实DOCX报告和XLSX执行台账，来源与虚构标记保留

## 保留0.2既有能力

- 角色各自模型地址/模型名称/独立内存Key，或继承全局配置；不同角色即使使用同一服务商也不混用Key
- 私有知识带ownerAgentId，检索/委派取权限交集；读取私有资料或邮件/网页后整个任务禁止跨角色转交，防止摘要绕过可见性
- 真实IMAP/SMTP适配器，TLS与STARTTLS验证、INBOX游标去重、完整不可变审批、并发一次发送、DATA后unknown、取消、改稿使旧审批失效、缺凭据后重输再审批
- 邮件工具接入模型循环，批准发送后继续当前任务；投递未知/部分收件人拒绝时停止并要求人工确认
- 通用目标白名单浏览器，控件观察、截图、精确动作审批、独占人工接管；两套不同DOM本地网站实际读写验证
- 浏览器工具接入模型循环，人工归还后重新观察规划并废弃旧审批；重启不重放会话或输入
- 对应角色、私有知识、真实邮件、浏览器工作台UI；真正的设置/表单/审批/停止操作

最终测试数量和界面回归结论以本版 `TEST-REPORT.md` 为准，不能使用旧版数字替代。

## 部署与测试解释

Linux本机功能真实执行，模型协议、邮箱账户和网站数据全部使用可控虚构夹具。源代码包不包含运行时，因此不是普通同事可双击安装的离线包。另已产出Linux目录发行包，包含本机验收的运行时，并在项目树外运行成功；它尚未做跨发行版或无网络安装验收。Windows离线安装器配方支持Windows原生或Linux x64交叉构建；此次Windows Electron已校验下载，但Windows Chromium官方下载返回不可用页面，完整安装器尚未产出。

当前环回地址不能从用户自己的电脑直接访问；不向公网暴露本地服务。可交付截图、代码与验证报告，原生Electron窗口用于本机核验。
